# QueryLens: project starter pack

QueryLens: Evaluation-Driven Development of a Text-to-SQL Analyst Agent on a Multi-Domain E-commerce Data Warehouse.

## Contents

- `CLAUDE.md`: implementation brief for Claude Code. Put it in the root of your repository.
- `docs/QueryLens_Design_v3.pdf`: architecture and method.
- `docs/QueryLens_Charter_and_Data_Spec.pdf`: names, row counts, eval-set counts, targets, free-tier plan.
- `latex_source/`: LaTeX source for both PDFs. Build with `pdflatex` twice.

## Start

1. Create an empty repository named `querylens`.
2. Copy `CLAUDE.md` into the repository root and `docs/` into `docs/`.
3. Create free accounts and API keys: Mistral, Google AI Studio (Gemini), Groq, OpenRouter. Install Ollama.
4. Open Claude Code in the repository and ask it to start Phase 0 from `CLAUDE.md`.
